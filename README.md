# Bangalore Pincode Explorer

A simple application to search Bangalore pincodes.

## Setup Instructions

1. Install backend dependencies:
cd server
npm install

2. Start the backend:
node server.js

3. Install frontend dependencies in another terminal:
cd client
npm install

4. Start the frontend:
npm run dev

## Features
- Search by pincode
- Search by area
- View all pincodes

## Tech Stack
- React
- Node.js
- Express
